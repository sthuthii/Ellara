PCOS Prediction and Ovarian Health Monitoring using Machine Learning

This project aimed to address the growing health concern of Polycystic Ovary Syndrome (PCOS) among women through the application of machine learning. The solution was developed with a dual focus to serve both general users and clinical settings.

The first module was designed for public use, enabling women to monitor their ovarian health by logging daily lifestyle and physiological data such as stress levels, weight fluctuations, sleep patterns, and menstrual irregularities. Using this self-reported information, a machine learning model—Random Forest Classifier—was trained to analyze trends and provide a prediction score indicating the likelihood of PCOS, offering an early warning system based on aggregated patterns over time.

The second module targeted clinical diagnosis by leveraging medical data, including ovary sizes, follicle counts, and hormonal levels (e.g., LH/FSH ratios). This structured dataset was also processed using the Random Forest Classifier, selected for its high accuracy and ability to handle both categorical and numerical variables effectively. The model provided reliable predictions based on clinical attributes, assisting healthcare professionals in PCOS diagnosis.

Together, these modules create a comprehensive tool that promotes awareness, early detection, and clinical support for managing PCOS through an intelligent, data-driven approach.
